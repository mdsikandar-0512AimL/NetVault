# NetVault — Network Router Configuration Store

A desktop application built using **Python, Tkinter, and SQLite** to manage network router configurations with version control support.

---

## Features

- Add, Edit & Delete Routers
- Store multiple versions of configurations (Startup / Running / Golden Template)
- Import configuration from `.cfg` / `.txt` files
- Export configuration as backup
- Version comparison using Diff
- Search routers by Hostname, IP, Vendor or Location
- Sample data included for demonstration

## How to Run

1. Clone the repository or download the project
2. Make sure **Python 3.8+** is installed
3. Open terminal in the project folder
4. Run the application:

```bash
python netvault.py
